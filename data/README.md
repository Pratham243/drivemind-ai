# Data directory

- `raw/dataset.csv` — generated by `scripts/generate_dataset.py`: `id, text, intent, split`.
- `annotated/dataset.jsonl` — fully annotated version (adds `entities`, `source`, `difficulty`), one JSON object per line, conforming to `src/annotation/schema.py`.
- `processed/` — reserved for any additional preprocessed/feature-extracted artifacts (currently unused; preprocessing is applied on-the-fly inside the model pipelines rather than materialized to disk).

None of these files are committed to git (see `.gitignore`) — they are fully reproducible:

```bash
python scripts/generate_dataset.py
python scripts/validate_dataset.py
```

Generation is deterministic given the seed in `configs/config.yaml` (`dataset.seed`).
